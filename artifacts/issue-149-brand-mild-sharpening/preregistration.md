# Issue #149 bounded Brand mild-sharpening preregistration

- Status: frozen before the first treatment run on this branch
- Base SHA: `4aac539c7d314cc0d57ed168e270f5191bed161d`
- Date: 2026-07-27
- Design: one-variable-at-a-time, evaluation-only

## Research question

Does one deterministic mild unsharp-mask operation improve bounded Brand recognition on the 11 governed, fixed-truth regions without increasing false certainty, empty OCR, or unacceptable runtime?

## Fixed corpus

The corpus is the committed `tests/fixtures/ocr-research/manifest.json` generated by merged PR #197:

- 10 governed real-label source fixtures;
- 11 reader-approved Brand regions;
- fixed Brand truth joined only after OCR;
- no local-private fixtures;
- deterministic case order by fixture ID and region index.

Related variants are not treated as independent:

- `la-fattoria`: `approved-wine-004`, `approved-wine-005`, and `la-fattoria-rotated`;
- `dry-cellar`: the two regions from `wine-multi-artifact-04`;
- every other fixture has its own independence family.

Both source SHA-256 and the preregistered independence family are reported.

## Control

The control is `PRODUCTION_BOUNDED_BRAND_CONTROL`:

- scale: `3`;
- padding: `3%`, minimum `4 px`;
- resize: Sharp cubic;
- grayscale: Sharp grayscale;
- contrast: Sharp `normalise`;
- threshold: none;
- sharpening: none;
- inversion: false;
- denoising: none;
- PSM: `11`;
- rotation: `0`;
- crop source: governed Brand region executed through the production-equivalent seller-region pass;
- OCR: local `tesseract.js`, English, OEM 1, cache disabled;
- production Brand grouping, filtering, ranking, reliability, and authority thresholds.

## Treatment

The treatment differs only in configuration field `sharpening`:

```json
{
  "control": "none",
  "treatment": "mild"
}
```

The `mild` operation is Sharp 0.35.3 `sharpen` with every parameter explicit:

```text
sigma = 1.0
m1    = 1.0
m2    = 2.0
x1    = 2.0
y2    = 10.0
y3    = 20.0
```

It runs after resize, grayscale, normalisation, and optional denoising, and before inversion or thresholding. No second strength or adaptive selection is allowed.

## Hypothesis

Sharpening may increase local edge separation for thin, anti-aliased, outlined, or mildly blurred glyphs, allowing Tesseract to recover characters or complete words. It may instead amplify texture, compression halos, or character joins. The treatment is valuable only if gains cross independent artwork/checksum families and preserve abstention safety.

## Frozen metrics

Per case:

- exact and normalized selected-value correctness;
- raw OCR truth recall;
- complete candidate-list and normalized top-3 truth recall;
- raw words, transcript, selected and normalized selected value;
- OCR mean confidence and selected evidence score;
- reliability and authority state;
- failure class;
- empty OCR;
- crop, preprocessed image, latency, RSS;
- visual slices, SHA-256 family, and independence family;
- change, improvement, regression, and mechanism classification.

Aggregate and slice metrics:

- exact and normalized top-1 accuracy;
- raw OCR, candidate-list, and top-3 truth recall;
- false reliable reads and rate;
- wrong reliable reads;
- empty OCR;
- correct-but-conservative cases;
- median and p95 latency;
- 95% Wilson intervals;
- per-slice accuracy, recall, empty OCR, false certainty, and latency.

## Success criteria

`ADOPT_FOR_LARGER_EVALUATION` is allowed only when all are true in the primary run and behavior reproduces:

1. at least 2 of 11 regions improve in normalized top-1 accuracy;
2. no previously normalized-correct region regresses;
3. false reliable reads remain zero;
4. wrong reliable reads remain zero;
5. empty OCR does not increase;
6. normalized top-1 accuracy improves;
7. improved cases span at least two independence families;
8. treatment median latency is no more than 125% of paired control;
9. treatment p95 latency is no more than 135% of paired control;
10. no production code path changes.

Both the primary and deterministic repeat must produce identical control and treatment behavior hashes. Each paired run must stay within both latency ceilings.

## Kill criteria

The deterministic decision is `KILL` if any are true:

- zero or one region improves;
- a false or wrong reliable read appears;
- empty OCR increases;
- gains occur in only one independence family;
- either paired run exceeds either latency ceiling;
- configuration isolation finds any change besides `sharpening`;
- expected seller truth reaches OCR or preprocessing;
- any `clean-background` case loses a previously achieved normalized top-1, raw OCR recall, or candidate recall, or becomes empty after a non-empty control;
- either arm's behavior hash changes on repeat.

If no kill criterion fires but the full success gate is not met, the decision is `INCONCLUSIVE_CORPUS_EXPANSION_REQUIRED`.

Criteria and parameters must not be weakened after treatment output is observed.

## Mechanism classification

Every changed case receives exactly one:

- `SHARPENING_RECOVERED_CHARACTER`
- `SHARPENING_RECOVERED_WORD`
- `SHARPENING_CHANGED_GROUPING`
- `SHARPENING_CHANGED_CONFIDENCE_ONLY`
- `SHARPENING_CREATED_ARTIFACT`
- `SHARPENING_CAUSED_EMPTY_OCR`
- `SHARPENING_NO_MEANINGFUL_EFFECT`
- `UNDETERMINED`

Artifact inspection may describe visible thin-stroke, edge-contrast, outline/shadow, texture, punctuation, anti-aliasing, merging, or noise evidence. It must not claim causality when the paired artifacts and metrics do not support it.
